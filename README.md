# 🏊‍♂️ Race Day Manager

Race Day Manager is a desktop application built using **Python** and **Tkinter** designed to help swimmers stay organized and focused during swim meets. 

## ✨ Features
* **Event Tracking:** Keep a clear log of all your upcoming races throughout the day.
* **Tiredness Logger:** Track how you feel physically between events to monitor your energy levels.
* **Smart Reminders:** Get helpful alerts so you never miss a warm-up or a race start.

## 🛠️ Built With
* Python 
* Tkinter (for the graphical user interface)

## 🚀 How to Run
1. Make sure you have Python installed.
2. Clone this repository.
3. Run the main script:
   ```bash
   python main.py
   ```
